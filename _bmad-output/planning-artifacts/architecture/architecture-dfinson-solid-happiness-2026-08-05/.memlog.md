- (question) Choose the evaluator design paradigm that fixes dependency direction, state ownership, and extension boundaries.
- (decision) Adopt a hexagonal modular monolith with an append-only run ledger. Binds evaluator domain boundaries, dependency direction, mutation paths, and extension points; prevents external SDK churn from entering domain logic and prevents retries or reruns from overwriting evidence.
- (decision) Evaluate two memrelay treatment paths as separate strata: shipped daemon plus MCP estimates agent-facing product benefit including transport and formatting overhead; direct MemoryEngine estimates an engine upper bound. Each has separate assignments, estimands, cost ledgers, intervals, and claim IDs; results are never pooled into one efficacy estimate.
- (question) Inspect AI is Beta. Determine whether a production-stable, local-first evaluation framework can own runs and evidence for custom Copilot SDK coding agents without forcing a hand-rolled orchestration layer.
- (decision) Pin Inspect AI as the local execution framework and authority for run execution truth. Preserve native .eval logs plus Inspect built-in JSON exports for compatibility and audit. The evaluator append-only ledger stores only experiment/run identity, assignment, lifecycle transitions, artifact hashes, and terminal inclusion status; it never duplicates Inspect events.
- (constraint) Integrate GitHub Copilot through the official Copilot SDK custom agent boundary. Do not rely on an undocumented OpenAI-compatible Copilot endpoint or expose GitHub credentials as OpenAI API keys.
- (decision) Place the evaluator in a separate evaluation/ Python project within the memrelay repository. It shares repository versioning and CI, may depend on the local memrelay source for engine-stratum tests, is excluded from the memrelay wheel and default runtime dependencies, and owns its own lockfile, CLI, schemas, tests, and artifacts.
- (decision) Primary Copilot-agent trials use host-native isolated runs. Every run receives a fresh temporary git workspace, MEMRELAY_HOME, graph, spool, socket/port, caches, and agent session directory; only the host Copilot SDK process accesses the existing subscription credential domain. Containers are permitted for framework, engine, grader, and fault tests that do not require Copilot subscription credentials. Shared writable trial state is forbidden.
- (decision) Define two non-interchangeable history protocols. Controlled efficacy trials restore immutable hash-addressed history bundles into every arm before assignment exposure. Longitudinal and ecological trials generate histories dynamically under their assigned sequence and use sequence-level estimands. Controlled and dynamic-history results have separate protocol IDs and are never pooled.
- (decision) Use a SQLite WAL append-only ledger for experiment/run identity, assignments, lifecycle transitions, artifact hashes, and inclusion state. Preserve Inspect .eval logs plus JSON exports as authoritative execution records. Store large immutable artifacts in a stdlib SHA-256 filesystem CAS. Materialize versioned Parquet analysis tables only from reconciled terminal evidence; DuckDB opens those tables read-only and never owns operational state.
- (direction) User switched from Coaching to Fast path and asked for the completed artifacts for review; make remaining low-risk decisions with explicit assumptions.
- (decision) Inspect runs in the control process and launches one isolated worker process per run attempt under a bounded local concurrency pool. A worker is never reused across arms or attempts.
- (decision) Split credentials by process. The Copilot SDK worker receives only host Copilot authentication and no OpenAI key. The memrelay framework process receives only the configured OpenAI API key and no GitHub token. Graders and analysis receive neither credential.
- (decision) A versioned YAML scenario catalog is the human-authored source for experiments. JSON Schema validation and a deterministic compiler generate Inspect Tasks, opaque assignments, fixture manifests, and traceability maps. Ad hoc production Task definitions are forbidden.
- (decision) Use stable opaque IDs for experiment, protocol, scenario, task, history, assignment, run, attempt, artifact, evidence, endpoint, and claim. IDs never encode treatment labels; every mutable revision gets a new content hash.
- (decision) The outer ledger state machine is planned, assigned, provisioned, running, exported, scored, reconciled, then included or excluded. Transitions append only. Retries create linked attempt IDs and never replace prior evidence.
- (decision) Treatment assignment is concealed from task agents, graders, and adjudicators. Only the assignment service resolves opaque arm codes at provisioning; exported views redact treatment-revealing fields by schema.
- (decision) Benchmark-native executable graders run in a separate credential-free process over an immutable workspace snapshot. Hidden tests, grader versions, dependencies, and expected evidence are hash-pinned. LLM judges are secondary only.
- (decision) Instrument control, agent, product, framework, retrieval, tool, grader, and evidence-export spans through a local OTel Collector. OpenInference is the stable semantic base; OTel GenAI Development fields pass through a pinned compatibility mapper; memrelay.eval fields are versioned.
- (decision) Reconcile every terminal run against required Inspect log, JSON export, OTel trace classes, grader output, cost ledger, workspace patch, and ledger transitions before inclusion. Missing primary evidence fails closed.
- (decision) Separate Copilot subscription usage from framework OpenAI API spend and local resource cost. Every cost value carries provider, source, price-table version, currency, unit, and estimated-versus-metered status.
- (decision) Use configuration files and explicit CLI arguments for non-secrets; use environment variables only at the credential-bearing process boundary. Persist redacted effective configuration and hashes with each run.
- (decision) Use typed domain errors and fail-closed validation. Only pre-exposure infrastructure failures may receive one protocol-authorized retry; all attempts remain in the ledger.
- (decision) CI runs schema, compiler, ledger, adapter-contract, grader, telemetry, reconciliation, and deterministic component tests without paid calls. Paid Copilot/OpenAI stages are explicit local or scheduled workflows with quota and wall-time circuit breakers.
- (decision) The evaluation project uses Python 3.11 and its own pyproject plus uv lock. Product code keeps its current hatch build and supported Python range; evaluation dependencies never enter the shipped wheel.
- (decision) Adopt package boundaries: domain, catalog, ledger, orchestration, adapters, evidence, scoring, analysis, cli, and tests. Dependencies point inward to domain ports; adapters may depend on external SDKs, domain may not.
